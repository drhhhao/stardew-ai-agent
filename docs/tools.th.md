# เครื่องมือ

**ภาษาไทย** · [English](tools.md) · [← README](../README.md)

เครื่องมือทั้งหมดที่ AI เรียกใช้ได้ แยกตามงาน MCP endpoint ของ farmer ทุกคน (`/mcp`, `/mcp/p1` … `/mcp/p3`) มีครบทุกตัว

- ⚡ = ไม่เสียเวลาในเกม — แค่นั้น ไม่ได้แปลว่าอ่านอย่างเดียวอีกต่อไป เครื่องมือ ⚡ บางตัวเขียนข้อมูลเกมได้:
  `pay`, `give` และ `name` เป็นการเปลี่ยนแปลงที่ไม่เสียเวลาแต่ทำทีละคำสั่งแบบ serialized ไม่ใช่การอ่านล้วน
  ส่วนการอ่านแบบเดียว (⚡ และ read-only) ทำงานใน observation lane: ตอบได้แม้ตอนที่ action กำลังทำงาน
  และผลลัพธ์ไม่ทวนสถานะท้ายซ้ำ ๆ เครื่องมืออื่นทั้งหมดคือ **action** ที่ใช้เวลาในเกม ทำได้ทีละอย่างต่อ farmer
  และต้องใส่ `reason` (เหตุผลที่คนดูเห็นบน overlay ไม่ได้เขียนไว้ในตารางด้านล่าง)
- 🔁 = เครื่องมือ legacy เพื่อความเข้ากันได้: MCP client เดิมยังเรียกใช้ได้ตามเดิม แต่ AI ในตัว mod จะใช้เครื่องมือแยกตัวใหม่แทน
  และ `/api/contract` จะระบุ `legacy: true` เพื่อให้ client ภายนอกย้ายไปใช้ตัวใหม่ได้ตั้งใจ
- argument ที่เป็น*ตัวเอียง*ไม่บังคับใส่
- ตัวนิยามเครื่องมืออยู่ในไฟล์ชั้นบนสุดของ [`mod/StardewMCP/Agent/`](../mod/StardewMCP/Agent/) ส่วนหน้าตาผลลัพธ์ดูได้ที่
  [HTTP API → Tool results](api.md#tool-results) (อังกฤษ)

## ดูรอบตัวและคิด

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `status` ⚡ | | วัน เวลา อากาศ (และของพรุ่งนี้) ดวง สถานที่ พลังงาน เงิน ของที่ถือ (อาวุธบอกดาเมจ) ของที่สวมอยู่ ตัวเลือกที่ค้างอยู่ และหน้าต่างบทสนทนาหรือเมนูที่เปิดอยู่ |
| `look` ⚡ | *`radius`*, *`kinds`*, *`diff`* | แผนที่รอบตัวแบบช่อง (ค่าเริ่มต้น 17×17 รัศมี 8) พร้อมคำอธิบายสัญลักษณ์และรายการสิ่งของที่เห็น รวมถึงผู้เล่นคนอื่น `kinds` (เช่น `["crops","debris"]`) กรองรายการ `diff=true` แสดงเฉพาะช่องที่เปลี่ยนไปจากครั้งก่อน (เวลาของเครื่องจักรที่นับถอยหลังไม่นับว่าเปลี่ยน) สายแร่และหินอัญมณีบอกชนิดให้ (Copper Node, Gem Node...) เครื่องจักรบอกว่าใส่อะไรอยู่และเหลืออีกนานเท่าไร |
| `inventory` ⚡ | | ของในกระเป๋า ของที่สวมอยู่ และของที่ติดคันเบ็ด อาวุธบอกดาเมจ |
| `farm_summary` ⚡ | | รายงานทั้งฟาร์ม: ดินที่ไถแล้วแต่ยังว่าง ผักแต่ละชนิดกับจำนวนวันที่เหลือ ต้นที่ยังไม่รดน้ำ ต้นที่สุกแล้ว ต้นที่ตาย ต้นที่โตไม่ทันฤดู ของป่า เศษไม้หิน บัวรดน้ำ แหล่งน้ำที่ใกล้ที่สุด และจำนวนเครื่องจักรทั้งฟาร์มที่เสร็จแล้ว กำลังทำ และว่างอยู่ (รายละเอียดดูที่ `machines`) |
| `think` ⚡ | `text` | ความคิดส่วนตัว ขึ้นบน overlay ไม่มีใครในเกมเห็น |

## เดินทาง

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `walk_to` | `x`, `y` | หาทางเดินไปยังช่องว่างในแผนที่ปัจจุบัน ถ้าช่องเป้าหมายติดหรือเดินไปไม่ได้ จะเดินไปยังช่องว่างที่ใกล้ที่สุดแทน พร้อมผล `no_path` แบบ partial ที่บอกสิ่งกีดขวางและเครื่องมือที่ควรใช้ (Pickaxe สำหรับหิน, Axe สำหรับต้นไม้/กิ่งไม้, Scythe สำหรับวัชพืช) หรือช่องข้างเคียงที่ควรเลือกต่อ ผลลัพธ์ยังบอกของที่เห็นระหว่างทาง การหาทางใหม่เมื่อชาวเมืองขวาง การจัดการประตูล็อก และการออกจากกำแพงยังเหมือนเดิม |
| `travel_to_location` | `location` | ไปแผนที่อื่น — ใส่ได้เฉพาะชื่อสถานที่ (Town, Beach, Mountain, Ginger Island...) การเดินทางไปร้านที่รู้เวลาจะถูกปฏิเสธก่อนร้านเปิด หลังร้านปิด วันหยุด/วันเทศกาล และ 30 นาทีก่อนร้านปิด ดู `calendar` ประตูอื่นที่ปิดจะบอกว่าเปิดกี่โมง และบอกของที่เห็นระหว่างทางแบบเดียวกับ `walk_to` เวลาเล่นหลายคน เกมให้เข้างานเทศกาลได้เฉพาะตอนที่เข้าพร้อมกันทุกคน จึงรอคนอื่นได้นานสุดหนึ่งนาที (นับเฉพาะตอนที่โลกเดิน และบอกให้เขารู้) ถ้าไม่มาก็เลิกรอแล้วแจ้ง `not_ready` แทนที่จะค้างอยู่ในกล่องรอ ถ้าทางออกที่ใกล้สุดไปแผนที่ถัดไปเดินไม่ถึง (มีประตูห้องนอนที่ล็อกขวางอยู่) จะลองทางออกอื่น ร้านค้าหรือเจ้าของร้านให้ใช้ `travel_to_shop` ส่วนชาวเมืองให้ใช้ `talk_to_villager` หรือ `give_gift` ไม่ใช่เครื่องมือนี้ |
| `travel_to_shop` | `shop` | เดินไปที่ร้านค้า โดยใส่ชื่อร้านหรือชื่อเจ้าของร้าน (Pierre, Clint, Marnie, Willy, Gus, Robin ฯลฯ) แล้วหยุดที่เคาน์เตอร์เพื่อให้ `shop_list` และ `buy` ใช้ได้ที่นั่น ระบบจะปฏิเสธการเดินทางก่อนร้านเปิด หลังร้านปิด วันหยุด/วันเทศกาล และ 30 นาทีก่อนร้านปิด พร้อมแนะนำให้ทำอย่างอื่นก่อน ดูเวลาใน `calendar` บอกของที่เห็นระหว่างทางแบบเดียวกับ `walk_to` ชื่อชาวเมืองไม่ใช่ปลายทาง — คุยหรือให้ของขวัญใช้ `talk_to_villager` / `give_gift` |
| `travel_to` 🔁 | `location` | (legacy AI ในตัว mod ใช้ `travel_to_location` และ `travel_to_shop` แทน) ไปแผนที่อื่น ใส่ชื่อเจ้าของร้านหรือชาวเมืองก็ได้ การเดินทางไปร้านที่รู้เวลาจะถูกปฏิเสธก่อนร้านเปิด หลังร้านปิด วันหยุด/วันเทศกาล และ 30 นาทีก่อนร้านปิด ดู `calendar` ประตูอื่นที่ปิดจะบอกว่าเปิดกี่โมง และบอกของที่เห็นระหว่างทางแบบเดียวกับ `walk_to` เวลาเล่นหลายคน เกมให้เข้างานเทศกาลได้เฉพาะตอนที่เข้าพร้อมกันทุกคน จึงรอคนอื่นได้นานสุดหนึ่งนาที (นับเฉพาะตอนที่โลกเดิน และบอกให้เขารู้) ถ้าไม่มาก็เลิกรอแล้วแจ้ง `not_ready` แทนที่จะค้างอยู่ในกล่องรอ ถ้าทางออกที่ใกล้สุดไปแผนที่ถัดไปเดินไปไม่ถึง (มีประตูห้องนอนที่ล็อกขวางอยู่) จะลองทางออกอื่น |
| `mount`, `dismount` | | ขี่ม้า (ต้องมีคอกม้า) และลงจากม้า |

## ทำฟาร์ม

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `use_tool` | `tool`, `tiles`, *`max_hits`* | ใช้เครื่องมือกับช่องเดียวหรือหลายช่อง (จอบ บัวรดน้ำ ขวาน อีเต้อ เคียว...) |
| `plant` 🔁 | `item`, *`tiles`* หรือ *`area`* | (legacy AI ในตัว mod ใช้ `plant_item` แทน) ปลูกเมล็ดหรือใส่ปุ๋ยบนดินที่ไถแล้ว: ระบุช่อง ระบุพื้นที่ `[x, y, w, h]` หรือไม่ระบุเลย = ทุกช่องที่ไถแล้วและยังว่างในแผนที่ |
| `plant_item` | `item` และอย่างใดอย่างหนึ่งใน `tiles` / `area` / `all_empty` + `confirm` | (action) ปลูกเมล็ดหรือใส่ปุ๋ยบนดินที่ไถแล้ว โดยต้องระบุขอบเขตชัดเจนอย่างใดอย่างหนึ่ง: ระบุช่องด้วย `tiles` ระบุพื้นที่ `[x, y, w, h]` ด้วย `area` หรือ `all_empty: true` พร้อม `confirm: true` สำหรับทุกช่องที่ไถแล้วและยังว่างในแผนที่ ถ้าไม่ใส่อย่างใดเลย หรือใส่ `all_empty` แต่ไม่ใส่ `confirm` จะไม่ปลูกอะไรเลย |
| `harvest` | `tiles` | เก็บผักหรือของป่าในช่องที่ระบุ |
| `water_all` | *`whose`* | รดน้ำทุกต้นที่ยังแห้งในแผนที่ (`whose: "mine"` = เฉพาะของตัวเอง) เติมน้ำที่แหล่งน้ำใกล้สุดที่เดินไปถึงเอง และบอกว่ารดของใครไปบ้าง |
| `harvest_all` | | เก็บผักที่สุกแล้วและของป่าทั้งแผนที่ |
| `clear_area` | `x`, `y`, `w`, `h` | เคลียร์พื้นที่สี่เหลี่ยม (ไม่เกิน 100 ช่อง) ด้วยเครื่องมือที่เหมาะ ตอไม้ใหญ่และหินก้อนใหญ่จะข้ามและแจ้งให้รู้ |
| `till_area` | `x`, `y`, `w`, `h` | ไถพื้นที่สี่เหลี่ยมด้วยจอบ |
| `place` | `item`, `tiles` | วางของ เครื่องจักร หีบ สปริงเกอร์ รั้ว หรือเฟอร์นิเจอร์ลงบนพื้น |

เครื่องมือแบบทำทีละหลายช่อง (`water_all`, `harvest_all`, `clear_area`, `till_area`, `plant_item` แบบพื้นที่) จะหยุดพร้อมบอกเหตุผล
(พลังงานต่ำ มีเมนูเปิด ดึกแล้ว กระเป๋าเต็ม) และบอกว่าเหลืออีกเท่าไร ส่วน `use_tool`, `plant_item` (และ `plant` แบบ legacy) และ `harvest` จะรายงานจำนวนช่อง
`done`, `remaining` และ `skipped` เสมอ

`tiles` รับ `[[x,y],...]` และรูปแบบอื่นที่โมเดลมักส่งมาแทน: `[{"x":1,"y":2}]`, `["1,2"]`, สตริงเดียว
`"[(1, 2), (3, 4)]"` หรือเลขเรียงกัน `[x1,y1,x2,y2]` ถ้าไม่มี `tiles` ใช้ `tile` ช่องเดียว หรือ `x` กับ `y` แทนได้ ตัวเลขในทุกเครื่องมือ
ส่งเป็นสตริงตัวเลข (`"12"`) หรือทศนิยมลงตัว (`12.0`) ได้

## ความรู้ในเกม ⚡

อ่านจากข้อมูลของเกมเอง (ส่วน `guide` อ่านจากหน้าคู่มือที่มากับ mod) ไม่เสียเวลาในเกม

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `crops` ⚡ | *`season`*, *`fertilizer`* | วางแผนปลูกตามฤดู: วันที่ใช้โตและโตซ้ำ วันสุดท้ายที่ยังปลูกทัน จำนวนรอบเก็บที่ทัน ราคาเมล็ดจากทุกร้านและทุกเทศกาล ราคาขาย (คุณภาพปกติ) ทองต่อช่องต่อวัน บอกว่าเมล็ดไหนมีติดตัว ต้นไหนจะตายเมื่อเปลี่ยนฤดู และมีรายการไม้ผลด้วย `season=greenhouse` วางแผนสำหรับเรือนกระจก `fertilizer` (`speed_gro`, `deluxe_speed_gro`, `hyper_speed_gro`) ลดวันที่ใช้โตแบบเดียวกับในเกม (ถ้ามีอาชีพ Agriculturist ก็คิดให้ด้วย) |
| `item_info` ⚡ | `name` | ค้นของได้ทุกแบบ: ของทั่วไป เครื่องจักรและของคราฟต์ชิ้นใหญ่ อาวุธ เครื่องมือ รองเท้า และหมวก บอกราคาขายแยกตามคุณภาพ (คิดอาชีพของเราให้ด้วย) กินแล้วได้อะไร ร้านที่ขายและราคา หาได้จากไหน (พืช ต้นไม้ สัตว์ จุดตกปลา ของป่า geode มอนสเตอร์ เครื่องจักร) ควรเก็บไว้ทำอะไร (bundle ที่ยังไม่ครบ พิพิธภัณฑ์ เควสต์ Special Orders) ของที่ได้จากเครื่องจักรที่คุ้มที่สุด วิธีได้สูตร และสูตรที่ใช้ของชิ้นนี้ อาวุธบอกดาเมจ ความเร็ว และคริติคอล เครื่องมือบอกค่าอัปเกรด |
| `fish_info` ⚡ | *`location`*, *`fish`*, *`season`*, *`weather`*, *`time`* | ปลาอะไรกินเบ็ดที่ไหนและเมื่อไร ถ้าไม่ใส่อะไรเลย: ปลาที่ตกได้ตรงนี้ตอนนี้ (ตามแผนที่ ฤดู เวลา อากาศ และเลเวลตกปลาของเรา) พร้อมราคา ช่วงเวลา อากาศ ความยาก เคยตกได้หรือยัง และ bundle ยังต้องการไหม ตามด้วยปลาของแผนที่นี้ที่ออกช่วงเวลาหรือฤดูอื่น ของที่ลอบดักปูจับได้ที่นี่ และปลาที่ bundle ต้องการซึ่งกำลังออกที่อื่นตอนนี้ `location` ดูแผนที่อื่น `fish` ดูทุกแผนที่และทุกช่วงเวลาของปลาตัวเดียว ส่วน `season`, `weather` (`rain` หรือ `sun`) และ `time` ใช้เปลี่ยนเงื่อนไขที่ตรวจ ปลาในตำนานจะขึ้นเมื่อเลเวลตกปลาถึงเกณฑ์ของมัน หรือขึ้นตลอดเมื่อเปิด `GuideKnowledge` |
| `machines` ⚡ | *`item`*, *`machine`* | `item=X`: เครื่องจักรทุกเครื่องที่รับ X พร้อมของที่ได้ ราคาขาย (คิดอาชีพของเรา) เวลาที่ใช้ กำไรต่อชิ้นและต่อเครื่องต่อวัน และตัวที่คุ้มที่สุด `machine=X`: เครื่องนั้นรับอะไร ทำอะไรได้ และต้องใช้เชื้อเพลิงอะไร ถ้าไม่ใส่อะไร: เครื่องจักรทุกเครื่องในฟาร์ม ในอาคาร และในบ้าน แบ่งเป็น เสร็จแล้ว / กำลังทำ (พร้อมเวลาเสร็จ) / ว่าง พร้อมพิกัดช่อง |

| `villagers` ⚡ | *`name`*, *`item`* | ชาวเมืองทุกคน: อยู่ที่ไหน หัวใจกี่ดวง วันนี้และสัปดาห์นี้คุยหรือให้ของแล้วหรือยัง วันเกิด ถ้าใส่ชื่อจะบอกสิ่งที่ยังขาดก่อนขอเดตหรือขอแต่งงาน ของขวัญชิ้นล่าสุดที่ให้ ของที่เขาชอบและไม่ชอบ และเขาจะรู้สึกยังไงกับของที่เรามี `item=X` บอกว่าใครชอบมาก ชอบ ไม่ชอบ หรือเกลียด X (ใส่ `name` ด้วยจะดูเฉพาะคนนั้น) ปกติจะรู้แค่รสนิยมที่รู้มาแล้ว (จากการให้ของและคำใบ้) ถ้าเปิด `RevealGiftTastes` หรือ `GuideKnowledge` จะเห็นทั้งหมดจากข้อมูลเกม ถ้าใส่ชื่อชาวไร่ด้วยกัน จะบอกให้คุยด้วย `say` |

## ของ คราฟต์ และทำอาหาร

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `craft` 🔁 | *`recipe`*, *`quantity`* | (legacy AI ในตัว mod ใช้ `list_recipes` + `craft_item` แทน) คราฟต์จากสูตรที่รู้ `craft()` แสดงสูตรทั้งหมด |
| `list_recipes` ⚡ | | สูตรคราฟต์ที่รู้ พร้อมวัตถุดิบ และว่าแต่ละสูตรทำได้กี่ชิ้นตอนนี้ อ่านอย่างเดียวไม่เสียเวลาในเกม |
| `craft_item` | `recipe`, *`quantity`* | (action) คราฟต์สูตรที่ระบุ ต้องใส่ `recipe` ไม่ใส่ชื่อสูตรจะไม่คราฟต์อะไรเลย |
| `cook` 🔁 | *`recipe`*, *`quantity`* | (legacy AI ในตัว mod ใช้ `list_dishes` + `cook_dish` แทน) ทำอาหารที่รู้สูตรในครัวบ้าน ใช้วัตถุดิบจากกระเป๋าและตู้เย็น `cook()` แสดงสูตรทั้งหมด |
| `list_dishes` ⚡ | | สูตรอาหารที่รู้ พร้อมวัตถุดิบที่นับจากกระเป๋าและตู้เย็น และว่าแต่ละจานทำได้กี่ชิ้นตอนนี้ อ่านอย่างเดียวไม่เสียเวลาในเกม |
| `cook_dish` | `recipe`, *`quantity`* | (action) ทำอาหารจานที่ระบุในครัวบ้าน ต้องใส่ `recipe` ไม่ใส่ชื่อสูตรจะไม่ทำอะไรเลย |
| `chest` 🔁 | *`x`*, *`y`*, *`action`*, *`item`*, *`items`*, *`quality`*, *`quantity`* | (legacy AI ในตัว mod ใช้ `list_chest`, `list_containers`, `open_container`, `store_items` และ `take_items` แทน ส่วน `stash` และ `create` ยังใช้ได้ที่เครื่องมือ legacy ตัวนี้) เก็บหรือหยิบของในหีบหรือตู้เย็นในครั้งเดียว: ตามชื่อและคุณภาพ หลายชิ้นพร้อมกัน หรือ "ทั้งหมด" `action=stash` จะหาหีบที่ใกล้สุด (หรือสร้างและวางหีบใหม่ด้วยไม้ 50 ชิ้น) แล้วเก็บทุกอย่างยกเว้นเครื่องมือ เมล็ดพันธุ์ และอาหารปรุง `action=create` สร้าง/วางหีบอย่างเดียว ผลลัพธ์จะบอกด้วยว่าตั้งแต่ใช้หีบนี้ครั้งก่อน มีใครใส่หรือหยิบอะไรไปบ้าง `action=all` แสดงหีบและตู้เย็นทุกใบในฟาร์ม ว่าเป็นของใคร มีอะไรอยู่ และใครเปลี่ยนอะไรไปล่าสุด (ไม่ต้องเดินไป) ถ้าชาวไร่อีกคนเปิดหีบอยู่ จะรอให้ปิด (ไม่เกิน 10 วินาทีของเวลาที่เดินอยู่) แล้วเปิดใหม่ |
| `list_chest` ⚡ | *`item`*, *`items`*, *`quality`* | อ่านเฉพาะหีบ ตู้เย็น หรือ grab menu ที่เปิดอยู่ตอนนี้เท่านั้น แบบอ่านอย่างเดียว (ไม่เสียเวลาในเกม): รายการของพร้อมคุณภาพและจำนวนช่องว่าง กรองตามชื่อหรือคุณภาพได้ ต้องเปิดหีบไว้ก่อนด้วย `open_container` ไม่ทำให้เวลาในเกมเดินต่อ |
| `list_containers` ⚡ | | บัญชีหีบทั้งฟาร์มแบบอ่านทีเดียว (ไม่เสียเวลาในเกม): หีบและตู้เย็นทุกใบ ว่าเป็นของใคร มีอะไรอยู่ และมีใครใส่หรือหยิบอะไรไปบ้างตั้งแต่ครั้งก่อนที่ใช้แต่ละใบ ไม่ต้องเดิน เวลาในเกมค้างอยู่ |
| `open_container` | `x`, `y` | (action) เดินไปข้างหีบหรือตู้เย็นที่ช่อง `x`, `y` แล้วเปิดมัน เมื่อเปิดแล้ว `list_chest`, `store_items` และ `take_items` จะทำงานกับหีบใบนี้ได้ ถ้าชาวไร่อีกคนเปิดหีบอยู่ จะรอให้ปิด (ไม่เกิน 10 วินาทีของเวลาที่เดินอยู่) แล้วเปิดใหม่ |
| `store_items` | `item`/`items`, *`quality`*, *`quantity`* | (action) เก็บของจากกระเป๋าเข้าหีบที่เปิดอยู่: ระบุชื่อชิ้นเดียว หลายชื่อ หรือ `item: "everything"` `quality` จำกัดเฉพาะคุณภาพนั้น `quantity` จำกัดจำนวนต่อชนิด (ค่าเริ่มต้น: ทั้งหมด) รายงานว่าอะไรย้ายไปแล้ว อะไรถูกข้ามหรือเหลืออยู่ ไม่มีอะไรถูกตัดทิ้งเงียบ ๆ |
| `take_items` | `item`/`items`, *`quality`*, *`quantity`* | (action) หยิบของจากหีบที่เปิดอยู่เข้ากระเป๋า: ระบุชื่อชิ้นเดียว หลายชื่อ หรือ `item: "everything"` `quality` จำกัดเฉพาะคุณภาพนั้น `quantity` จำกัดจำนวนต่อชนิด (ค่าเริ่มต้น: ทั้งหมด) รายงานว่าอะไรย้ายมาแล้ว อะไรใส่กระเป๋าไม่พอ ไม่มีอะไรถูกตัดทิ้งเงียบ ๆ |
| `equip` | `item`, *`slot`*, *`count`* | ทางเข้าเดียวของทุกอย่างที่สวมใส่ได้: สวมหมวก เสื้อ กางเกง แหวน หรือรองเท้า (ของเดิมกลับเข้ากระเป๋า) หรือติดเหยื่อและอุปกรณ์เข้าคันเบ็ด |
| `wear` 🔁 | `item` | (legacy AI ในตัว mod ใช้ `equip` แทน) ใส่หมวก เสื้อ หรือกางเกงจากกระเป๋า |
| `wardrobe` ⚡ | | ดูว่าใส่อะไรอยู่และมีเสื้อผ้าอะไรติดตัว |
| `eat` | `item` | กินหรือดื่ม |
| `trash` | `item`, *`quantity`*, *`quality`*, *`confirm`* | ทิ้งของ (ทิ้งเครื่องมือไม่ได้ ของมีค่าต้องใส่ `confirm`) |

| `read_sign` | `x`, `y` | เดินไปข้างป้ายที่ช่อง `x`, `y` แล้วอ่านข้อความบนป้าย โดยคัดข้อความมาให้ในผลลัพธ์ เป็น action ที่ใช้เวลาในเกม ไม่ใช่การอ่านแบบทันที ป้ายที่อยู่ในจอจะถูก `look` ติดป้ายไว้ด้วยว่า `A Sign: ...` |
| `load_machine` | `item`, `x`, `y` | (action) ถือของชิ้นที่ระบุแล้วกดปุ่ม action ที่เครื่องจักรบนช่อง `x`, `y` — เช่น Copper Ore ใส่ Furnace เหยื่อลงกับดักปู ทำงานเดียวที่ตั้งใจไว้ ไม่กระตุ้นอย่างอื่นบนช่องนั้น |
| `use_held_item` | `item` | (action) ถือของชิ้นที่ระบบแล้วใช้ที่ตรงที่ยืน (`performUseAction`): Warp Totem หนังสือ Secret Note ไม่กดที่ช่องไหน จึงไม่กระตุ้นอะไรข้าง ๆ โดยไม่ตั้งใจ |
| `choose_profession` | `option`, *`skill`* | เลือกอาชีพที่ค้างอยู่ (สกิลเลเวล 5 และ 10) เลือกแล้วเปลี่ยนไม่ได้ |

## เวลา การนอน และความจำ

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `wait` | `minutes` | ปล่อยให้เวลาผ่านไป |
| `rest` | *`minutes`* | นอนพักบนเตียงตัวเองเพื่อฟื้นพลังและเลือดระหว่างที่เวลาเดิน (ใช้ได้เฉพาะตอนเล่นหลายคน — ถ้าอยู่คนเดียวเตียงไม่คืนพลังและจะถูกปฏิเสธ) จบเมื่อพลังเต็ม ครบเวลา หรือมีคนเรียก |
| `journal` ⚡ | `diary`, `lessons`, `plan`, *`notes`*, *`self`*, *`people`*, *`day`* | ความจำข้ามวันของ AI: ไดอารี่ให้คนดูอ่าน บทเรียน (ต่อท้าย) แผนแบ่งเป็น ฤดู / สัปดาห์ / วันนี้ ข้อเท็จจริงเพิ่มเติม บันทึก `self` (ตัวเองเป็นใคร เขียนทับทุกเย็น) และ `people` หนึ่งบรรทัดต่อเพื่อนร่วมฟาร์มแต่ละคน `day` ใช้เขียนย้อนวันที่พลาดไป |
| `sleep` | *`confirm_early`* | จบวัน ไม่บังคับเขียน `journal` ก่อน — การเขียนไดอารี่คือนโยบายของตัวรัน ไม่ใช่กฎของเกม ถ้ายังรู้สึกกระปรี้กระเปร่าในช่วงเช้า (ก่อน 17:00 และพลังงานยังเหลือเยอะ) จะถูกปฏิเสธพร้อมคำเตือนหนึ่งครั้ง เว้นแต่ใส่ `confirm_early: true` ยืนยันว่าตั้งใจจะนอนจริง ๆ เวลาเล่นหลายคนจะนอนรอเพื่อนร่วมฟาร์มบนเตียง (และบอกให้เขารู้) เหตุการณ์ตอนกลางคืนจะกลับมาเป็นบรรทัด `Overnight:` |
| `go_to_bed` 🔁 | | (legacy AI ในตัว mod ใช้ `sleep` แทน) จบวัน จะไม่ยอมนอนจนกว่าจะเขียน `journal` ของวันนี้ ถ้ากระปรี้กระเปร่าก่อน 17:00 จะเตือนหนึ่งครั้งแล้วยอมให้เรียกซ้ำอีกครั้ง ถึงจะยอมนอน เหตุการณ์ตอนกลางคืนจะกลับมาเป็นบรรทัด `Overnight:` |

## เล่นด้วยกัน (จอแบ่ง)

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `say` ⚡ | `text` | พูด: ขึ้นในกล่องแชตและเหนือหัว ได้ยินเฉพาะผู้เล่นที่จอเห็นเรา `@ชื่อ` ใช้เรียกให้อีกคนหันมาฟัง |
| `emote` ⚡ | `name` | แสดงอีโมตเหนือหัว |
| `give` ⚡ | `to`, `item`, *`count`* | ยื่นของให้ผู้เล่นที่อยู่ใกล้ ไม่เสียเวลาในเกม แต่เป็นการเขียนข้อมูลที่ทำทีละคำสั่งแบบ serialized ไม่ใช่การอ่านล้วน |
| `pay` ⚡ | `to`, `amount` | โอนเงิน (ดู *ร้านค้าและเงิน* ไม่เสียเวลาในเกม ทำ serialized เช่นเดียวกับ `give`) |
| `propose` | `to` | ขอผู้เล่นอีกคนแต่งงาน |
| `answer_proposal` | `accept` | ตอบคำขอแต่งงานของผู้เล่นอีกคน |

farmer แต่ละคนเห็นกันแค่ไหน: `look` และ `status` แสดงผู้เล่นคนอื่นที่อยู่ในจอ พร้อมเครื่องมือที่เขา *กำลังใช้จริง* เหตุผล และใช้ไปนานเท่าไร
เทียบกับประโยคล่าสุดที่เราได้ยินเขาพูด ส่วน @ชื่อ การได้ของ ผู้เล่นเดินเข้ามาในจอหรือเข้าบ้านเรา ของในหีบหรือแปลงเราถูกหยิบ
ฝนเริ่มตก หรือมีกาลงฟาร์ม จะกลับมาเป็น `Events:` ในผลลัพธ์ถัดไป และหยุด `wait`, `walk_to`, `travel_to` หรือการทำฟาร์มที่ทำค้างอยู่
